# Marcos Andaya — Portfolio Website

Plain HTML, CSS and JavaScript. No build step. Open `index.html` to preview.

## Publish with GitHub Pages
1. Create a GitHub repository.
2. Upload the *contents* of this folder to the repository root (not the zip itself).
3. Settings → Pages → Deploy from a branch → `main` / `/(root)` → Save.

## Change things later
- Email: `script.js`, line 5 (`const EMAIL = '...'`). Right-click the file → Open with → Notepad.
- Text: `index.html`. Colours: top of `style.css`.
- Photos: `assets/portrait.jpg` (hero) and `assets/profile.jpg` (About).
- Social preview image: for it to show when the link is shared, change the `og:image` line in `index.html` to your full site address, for example `https://yourname.github.io/portfolio/assets/portrait.jpg`.

## Files
- `index.html` — all content
- `style.css` — design and animation
- `script.js` — menu, typing line, counters, filters, image viewer
- `assets/` — photos, samples, certificates, MLD logo
